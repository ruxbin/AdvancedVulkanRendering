# Volumetric Light Map 烘焙设计

日期：2026-10-01（起草）；2026-10-02（自查）

状态：阶段 1 的均匀网格烘焙、资产与 Vulkan 运行时已实现；数值与加载 smoke 验证见 `docs/vlm-phase1-validation.md`。完整画面对拍、薄墙漏光与性能预算尚未验收，阶段 2–4 未完成。

范围：Vulkan 离线 GPU 烘焙与运行时漫反射 GI。本文是设计规格，不代表功能已经实现或质量已经验证。

## 1. 目标与边界

为静态场景和动态物体提供空间连续、与接收表面法线相关的烘焙漫反射光照。采用离线路径追踪生成 SH9 光照场；先以均匀网格验证，再扩展为自适应稀疏砖块。无需为接收物体生成 lightmap UV。

沿用已确认方案的工作假设：场景主体、烘焙灯光与环境固定，动态物体只接收光照，不参与静态烘焙。场景长度单位必须通过场景加载数据与已知物体尺寸验证；下文以米表示的参数只在单位换算明确后使用。用户尚未指定目标 GPU、绝对性能和内存预算，因此本文不承诺毫秒级性能。

首个可验收闭环为：显式 BakeVolume、均匀探针、物理 SH9、静态太阳/点光/聚光灯和天空、烘焙文件保存加载、Vulkan deferred 与 forward 共用采样。后续增加稀疏砖块和可见性质量档，各阶段可以独立验证。

本设计不包括实时 GI 更新、动态物体反向贡献间接光、镜面反射烘焙、玻璃折射与焦散、体积雾光照接入、DX12 烘焙后端、关卡流式加载。静态门开启、几何移动、环境或灯光变化会使相关 GI 过期。运行时消费资产无需硬件光追，烘焙端需要现有 Vulkan RT 能力。

VLM 是低频空间光照表示；不能承诺表面 lightmap 的接触细节。SH 截断误差、空间插值误差和蒙特卡洛噪声必须分别评估。

只抽取烘焙所需的共享接口，不在本工作中全面重构渲染器。共享修改必须保留现有相机 PT 与 IBL 兼容模式的行为。

## 3. 光照所有权与单位

| 贡献 | 所有者 |
|---|---|
| 太阳、点光源、聚光灯对接收面的直接光 | 运行时直接光与阴影 |
| 上述解析灯经过至少一次表面散射的光 | VLM |
| 天空直接到达接收点的光与后续反弹 | VLM，包含静态场景可见性 |
| 自发光表面对其他物体的照明及反弹 | VLM |
| 当前可见表面自身的 emission | 表面着色器 |
| 镜面环境反射 | 原有 specular IBL 等反射路径 |

从探针出发的首段射线直接 miss 时返回天空；命中发光表面时记录其出射 emission；命中普通表面时计算其向探针方向的出射辐射。探针原点没有材质和法线，也不额外进行解析灯直接光 NEE。在首个命中表面进行解析灯 NEE 已经是到最终接收点的一次反弹，不应跳过。

有效 VLM 覆盖区内替换 diffuse IBL，保留 specular IBL，禁止完整 VLM 再叠加原有天空 diffuse SH。VLM 边界处用同一权重在 VLM 与物理天空 diffuse fallback 之间混合，禁止相加。

环境采样使用原始线性 HDR，不使用为 Apple 示例显示行为转换过的环境 cube。沿用 `DirectionToEquirectUV` 的方向映射，但不继承 Apple SH 的幅度/轴反射变换。曝光、tone mapping 与预览亮度不进入烘焙数据。现有 `iblScale` 不隐式作用于 VLM；调试强度独立且默认 1。

环境配置显式选择 `analyticSun` 或 `environmentSun`：前者要求使用不含对应太阳盘能量的环境，后者不再添加重复的解析太阳光。不得默认从任意 HDR 自动准确扣除太阳盘。发光几何与其代理解析灯也须指定唯一照明来源；首版不支持同一发光体双重计能。

当前 bundled HDR 保留太阳盘，所以阶段 1 CLI 默认 `environment`：烘焙跳过解析太阳 NEE，VLM 启用时运行时也抑制解析太阳直射。`analytic` 仅用于无对应太阳盘的天空或常量环境测试。关闭 VLM 保留已有渲染行为。

VLM 输出物理辐照度 E。Lambert 基准为 `Lo = diffuseReflectance * E / pi`。生产 PBR 中 diffuseReflectance 由材质金属度与约定的漫反射能量分配确定，不能直接把金属的 baseColor 当漫反射反射率。与现有角度相关 Fresnel BRDF 的差异属于接收端近似，应在对拍中单独记录。

## 4. 模块与数据流

```text
GpuScene + 固定几何/材质/灯光/环境
                 |
                 v
             BakeScene
                 |
                 v
 VlmLayoutBuilder -> 有效性检查 -> 预烘焙/细化
                 |
                 v
             VlmBaker
      路径积分 -> SH/方差/可见性累计
                 |
                 v
       去振铃 -> 边界处理 -> 量化
                 |
                 v
             VlmAsset
                 |
                 v
            VlmRuntime
    上传/寻址/插值 -> deferred + forward
```

| 模块 | 输入与输出 | 依赖 |
|---|---|---|
| `BakeScene` | 场景快照 -> 只读几何、材质、灯光、环境和 AS 视图 | 场景加载与 RT 资源 |
| `VlmLayoutBuilder` | BakeVolume、几何查询、预烘焙统计 -> 布局与有效性 | 不依赖显示帧或相机 |
| `VlmBaker` | 快照、布局、设置 -> FP32 累计结果、checkpoint | GPU 积分器 |
| `VlmAsset` | 烘焙结果 -> 版本化文件；文件 -> 已验证 CPU 数据 | 不依赖 Vulkan 句柄 |
| `VlmRuntime` | 已验证资产 -> GPU 资源与统一采样接口 | Vulkan 资源管理 |

统一采样语义为 `SampleVlm(worldPosition, shadingNormal, geometricNormal)` 返回物理 E、覆盖率与有效性。接收材质和显示变换不放入采样函数。法线偏置使用 geometricNormal，SH 方向求值使用 shadingNormal；两者在插值阶段不混淆。

## 5. 探针布局

### 5.1 均匀网格

BakeVolume 为显式世界空间 AABB，包含玩家可达空间及动态物体活动区域；不直接使用整个场景 AABB。首版只支持一个体积。

给定步长 h，各轴 cell 数为 `ceil(extent/h)`，probe 数为 `cellCount+1`。存储实际对齐后的 bounds、步长与各轴 probe 数；最大边界的查询必须选取最后一个有效 cell 并令局部坐标为 1，不能访问第 N 个不存在的邻居。

探针保持规则位置。利用双面几何距离查询、背面命中统计和多方向检测识别实体内或过近探针。对开放网格，背面比例仅是启发式，不能视为可靠的 inside 判定；标记低置信度并提供可视化或局部排除体积。

首版不重定位探针，以免偏移后仍按规则网格进行错误插值。无效样本不作为黑色有效样本参与平均，也不盲目复制最近亮探针。任何修补必须使用遮挡约束；无法可靠修补时保留无效状态并报告覆盖缺口。

### 5.2 自适应砖块

最终布局采用固定数量 cell 的叶砖块与八叉细分。本文明确选择每砖块 `4×4×4 cells`、`5×5×5 probe nodes`；这不是声明与 UE 二进制布局兼容。

根网格覆盖 BakeVolume，根条目索引扁平八叉节点；节点记录子节点基址或叶砖块索引。运行时从根坐标开始最多遍历配置的 maxLevel，不建立随最细分辨率三次方增长的全域稠密 indirection volume。

相邻叶层级差限制为 1。加密依据为几何距离、薄墙/门窗重要区域，以及预烘焙光照相对于粗层重建的残差；残差须超过噪声估计后才触发细化。预算同时限制探针、节点、边界数据和 GPU 总字节数；超预算报告具体区域与所需内存，不静默删除关键探针。

同级共享位置仅积分一次，打包时复制同一结果。基础档粗细交界的细侧边界 SH/有效性场由粗侧重建，内侧一层 cell 向独立细侧结果过渡，保证面上两侧求值一致；这是明确的局部精度让步。室内质量档不对不相同位置的距离矩执行这种简单重建，应分别完成粗/细层的可见性加权查询，再在细側过渡带混合有效结果。过渡带可能放大粗层漏光，需要通过后述门洞/薄墙测试决定是否继续加密。

Atlas 寻址使用 voxel-center 约定，采样足迹限制在当前砖块的节点范围，提供边界保护 texel，禁止串入不相邻砖块。没有经过专门边界处理的普通 mipmap 不用于 VLM。

## 6. 积分器与调度

首段必须覆盖全球。常量环境采用按 probeId/batchId 扰乱的均匀球面低差异方向，pdf 为 `1/(4*pi)`。阶段 1 实测 bundled HDR 的窄太阳盘使纯均匀采样在 65536 samples 下仍有严重方差，因此 integrator 3 的 HDR 首段改为 50% 均匀球面与 50% 环境重要性采样的混合，投影除完整 `p = 0.5/(4*pi) + 0.5*pEnv`。环境 CDF 以亮度乘球面 texel 面积构建，cell 内均匀采样 cos(theta)，PDF 使用实际上传 CDF 的差值。均匀分量保留全方向支持；这只改变首段采样，不额外添加环境光贡献，也不替代后续反弹的环境 NEE/MIS。探针没有接收法线，首段不能使用固定半球余弦采样。

命中后使用统一材质解码，处理线性 albedo、金属度、roughness、emission 与 alpha-test。首版不追踪透射；透明材质的烘焙策略显式为忽略遮挡或作为不透明阻挡，写入 bake 设置，避免悄悄把玻璃视为正确透射。

太阳与局部灯 NEE 在所有允许的表面命中执行。首版允许遍历全部点光和聚光灯作为正确性基线；数量扩大后改为具有明确选择 pdf 的光源采样。BSDF 混合采样须使用完整混合 pdf，与返回的 BRDF 权重一致。

天空和发光面首版可以通过方向/BSDF 命中积分；小而亮的光源会高方差，不能仅因平均画面稳定就宣布收敛。加入环境或发光面 NEE 时必须与 BSDF 命中使用 MIS，或明确不重叠的路径所有权，避免同一贡献重复累计。太阳盘采样也必须与指定的光源模型和能量归一化一致。

从第三次表面散射后执行 Russian Roulette。积分以线性 HDR FP32 累积；不继承固定的 radiance/throughput clamp。可选异常值抑制默认关闭，开启时在结果元数据中标明有偏，并保留未抑制基准。NaN/Inf 导致当前批次失败，不能当成零样本计入均值。

每个 probe 以独立 batch 的 SH 系数和若干固定方向 E 重建值估计方差；达到最小样本数后，以绝对和相对误差联合判据判断收敛。暗区使用绝对误差，避免除以接近零。到达样本预算仍未收敛时输出明确标记，允许用户查看或追加烘焙。

任务按 probe batch × sample batch 拆分，记录 GPU 时间并调整下一批规模。取消只在完成当前批次、完成资源同步后生效；显示累计工作量与收敛情况，不用已发射样本比例假装质量进度。

纹理在任务期间固定驻留与 mip 策略，不接受 streaming 替换；几何与灯光变动立即使快照失效。checkpoint 保存布局哈希、场景哈希、积分器版本、样本序列版本、每 probe 的样本计数、FP32 系数和方差状态。恢复必须逐项匹配。

## 7. SH 约定与存储

采用实数正交 SH，顺序与物理 `ComputeSH9FromEquirect` 一致：常量、y、z、x、yx、yz、3z²-1、zx、x²-y²。方向为世界空间，从探针指向入射光源一侧。

入射 radiance 投影为：

```text
L_j(p) = mean( radiance(p, wi) * Y_j(wi) / pdf(wi) )
E(p,n) = sum_j A_band(j) * L_j(p) * Y_j(n)
A = [pi, 2*pi/3, pi/4]  // l=0,1,2
```

首段不额外乘接收余弦。发布资产存储已经卷积、并折入基函数常数的物理辐照度多项式系数，与 `ComputeSH9FromEquirect` 输出语义一致；运行时不再卷积，也不再乘基函数归一化常数。资产编码标识为 `IrradiancePolynomialSH9_v1`，禁止加载 Apple compatibility SH 为同一类型。

按 `j*3+rgbChannel` 展平 27 个数，顺序填充 7 组 RGBA16F；第 28 个通道保留为 0。每 probe SH 数据为 56 B。线性系数必须使用有符号格式；负系数合法，不能逐系数截断。

去振铃对高阶 band 作受控衰减并保持 DC，记录处理前后误差。最终重建的小幅负 E 可截为零；显著负值先作为质量错误报告。量化前检查 FP16 有限范围；溢出时拒绝打包并报告探针，不静默饱和造成能量损失。

10 万个实际存储 probe 的 SH 约 5.6 MB（十进制）；稀疏砖块边界复制、保护 texel、索引与有效性另计。不能把去重后的逻辑 probe 数直接当 Atlas 实际存储数。

## 8. 运行时采样与漏光控制

### 8.1 基础档

用世界坐标找 cell，获取 8 个邻居，以三线性权重乘有效性后归一化，再在 shadingNormal 上重建 E。首版使用显式 gather，便于检查错误。可优化为预乘有效性的系数纹理与单独权重纹理过滤，但这种优化只实现空间/有效性权重，不代表具备遮挡权重。

probe 不重定位。着色点沿 geometricNormal 的查询偏置以 cell 大小的比例配置，并限制最大值；不能用大偏置掩盖墙体漏光。调试图同时显示原点与实际查询点。

### 8.2 室内可见性质量档

每 probe 额外保存方向性第一交点距离矩：8×8 八面体有效 texel，RG16F 为归一化距离的一阶与二阶矩，带 1 texel 八面体边界后物理尺寸为 10×10。每 probe 为 400 B，可见性内存通常大于 SH 内存。

距离使用 `d/Dmax`，其中 Dmax 覆盖体积内最长有效查询距离；miss 为 1，资产记录 Dmax。距离矩采用独立的全方向几何采样与正确的角域权重，不要求只靠光照重要性采样凑够样本，也不能把距离平方当成均值的平方。使用与烘焙一致的 alpha 遮挡语义。

运行时按 probe 到着色点的方向采样矩，利用方差和距离估计可见性。基本规则为距离不超过均值时保留权重，否则采用 `variance/(variance + deltaDistance²)`，结合最小方差、距离偏置与可调漏光抑制参数。该结果是启发式可见性权重，不是精确概率或薄墙保证。

各邻居的空间、有效性和可见性权重相乘后归一化。需要逐 probe 读取，不能直接用一次 3D 三线性过滤替代。若增加方向/法线权重，应使用 geometricNormal 并通过常量场测试，避免 normal map 造成错误的权重跳变。

### 8.3 Fallback 与边界

权重不足时，先查询有效且通过对应可见性判据的父层结果；均匀布局无父层。仍无结果的体积内部返回零 GI 并标记覆盖缺口，不直接回退明亮全局天空。该保守策略可能形成暗区，必须由探针覆盖修复。

显式体积外部回退物理天空 diffuse；体积边界在预设的一层粗 cell 过渡带内混合。BakeVolume 应包住建筑和活动范围，不能把过渡带放在室内外遮挡边界。原有 Apple diffuse IBL 模式只作为整体关闭 VLM 后的旧模式保留，不与物理 VLM 在边界直接混合。

SSAO/SAO 与材质 AO 在 GI 对拍时关闭；若保留接触增强作为运行时选项，只作用于明确的间接光分量并默认强度为零，避免把烘焙静态遮挡重复乘入。

## 9. 资产格式与失效策略

发布文件为 `.vlm`，采用小端序字段和分块数据，不直接序列化带编译器 padding 的 C++ struct。

| 区块 | 必需内容 |
|---|---|
| Header | magic、版本、字节序标识、编码、布局类型、总长度、块表和校验值 |
| Scene identity | 几何/变换、材质纹理内容、灯光、HDR、方向约定、烘焙设置哈希 |
| Volume | 单位换算、bounds、根步长、层级、Dmax、边界过渡参数 |
| Layout | 均匀维度或根表/八叉节点/砖块表、有效性 |
| Lighting | SH9 数据及明确 packing 描述 |
| Visibility | 可选距离矩、tile 布局及采样约定 |
| Diagnostics | 样本统计、未收敛计数、去振铃和有偏选项、积分器版本 |

加载时验证每个 offset/count/stride 的溢出与文件边界，拒绝未知编码、非有限参数和不完整文件。哈希不匹配时标记 stale，默认禁用该资产；调试模式可显式加载过期资产并持续显示状态。

checkpoint 与发布文件分离。写入采用临时文件、校验后原子替换；任务失败或取消不破坏上一次成功发布的资产。首版场景变化触发全量重烘，不承诺局部依赖追踪式增量更新。

## 10. 调试与验收

调试显示包括：probe 球、层级、无效/低置信度、方向 SH lobes、未收敛误差、距离矩、最终插值权重、fallback 区域，以及仅 VLM/仅直接光/完整合成视图。性能记录包含目标 GPU、分辨率、probe 数、实际分配字节、射线批次耗时与 VLM 查询 GPU 时间。

| 验证 | 方法与判据 |
|---|---|
| 常量天空 | 无几何、L=1；CPU 物理 SH 与 GPU 烘焙在固定法线组上 E≈pi，相对误差不超过 1% |
| 方向约定 | 轴向及斜向有限面积亮斑，比较同一积分的 CPU/GPU SH 系数，排除镜像、负法线和重复卷积 |
| SH 表示误差 | 高角分辨率积分 -> FP32 SH 为单独基线，不把方向光的 SH 截断误差算成积分器错误 |
| 量化 | 在常量和有限动态范围测试上比较 FP32/FP16 的重建 E，归一化误差低于 1%；零附近用固定参考亮度归一化 |
| 光照所有权 | 天空、太阳、点灯、聚光灯、发光分别启用；验证 VLM 开关不重复叠加直接光与天空 |
| 反弹正确性 | 漫反射箱体与拐角局部灯，比较一次/多次反弹；同材质同光源参考下检查局部灯后续 NEE |
| 插值连续性 | 恒定/仿射系数场跨 cell、同级砖块及粗细边界；数值测试边界极限一致，动态接收物体无阶跃 |
| 薄墙与门洞 | 封闭双室、一侧亮另一侧无光；记录暗室相对亮室污染，质量档目标低于 1%，达不到则明确报告并加密或调整遮挡数据 |
| 保存恢复 | 相同场景与种子分批中断恢复，样本序列不重叠、不遗漏，结果与不中断执行在浮点累计容差内一致 |
| 失败处理 | 取消、NaN、超预算、坏文件、版本/哈希不匹配不发布部分结果，不破坏旧资产 |
| 运行时成本 | 分别测基础档与可见性档，报告实际内存和 GPU 开销；目标硬件确定后再冻结产品性能门槛 |

参考渲染必须先去除当前 PT 的已知限制，并匹配材质、环境、光源单位与输出空间。GI 对拍以线性 HDR 的 diffuse 分量为准，关闭 tone mapping、曝光调整与 AO 后测量。低噪声参考与 VLM 对比时同时展示探针处误差、SH 压缩误差和插值误差，不只比较最终截图。

## 11. 实施阶段

1. **均匀网格闭环**：静态快照、独立探针 raygen、物理 SH9、文件保存加载、deferred/forward 接入、常量/方向/所有权验证。先以小型受控场景验收。
2. **积分与覆盖质量**：Bistro 子区域、局部灯多次反弹、发光高方差检测、有效性、断点续烘和失效检测。未通过数值与遮挡基准前不扩展全场景。
3. **稀疏布局**：预烘焙细化、2:1 层级约束、同级共享、粗细过渡、Atlas 与内存预算。重新执行连续性和能量测试。
4. **室内质量档及优化**：距离矩、逐 probe 可见性权重、薄墙/门洞验收；有测量证据后选择过滤优化或光源采样优化。

这些阶段描述实现依赖，不是已经批准的执行计划。书面规格审阅通过后，再编写带文件范围、验证命令和交付切片的实施计划。
